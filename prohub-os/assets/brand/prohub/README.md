# Prohub brand assets

- `prohub-logo.svg` — full lock-up (monogram + wordmark). Vectorised from the end frame of Prohub's own promo
  reel (averaged over 60 frames, colour-separated and traced). Paths: `#mark` (white P/H monogram),
  `#swoosh` (orange, `#FD8D18`), `#wordmark` (white "PROHUB"). Designed for dark backgrounds.
- `prohub-mark.svg` — monogram only.

Replace these with the master vector files from the original designer when available; the trace is faithful at
social-video sizes but is not a substitute for the source artwork in print.
