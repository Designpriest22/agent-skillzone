# Prohub × Live Out Loud: 20 s reel

A brutalist portfolio reel: 1080×1920, 30 fps, 20 s, cut on a 120 bpm original score.

| Time (s) | Scene |
|---|---|
| 0–2 | LIVE / OUT / LOUD, × WIZKID |
| 2–5 | Walk-out footage |
| 5–7.5 | Poster wall |
| 7.5–8 | 13 DEC |
| 8–10 | Stage and pyro footage |
| 10–12.5 | WhatsApp EN / HA, reel, website |
| 12.5–15 | Newspaper, word hunt zoom |
| 15–17.5 | Merch |
| 17.5–20 | Prohub |

- `reel.html`: the timeline
- `score.py`: the original score
- `render.mjs`: renders the reel (`node render.mjs 3.5 9` renders stills instead)
- `tools_garments.mjs`: the garment cut-outs

Footage frames (`clips/`) and the rendered MP4 are git-ignored because they contain artist footage and this repository is public.
