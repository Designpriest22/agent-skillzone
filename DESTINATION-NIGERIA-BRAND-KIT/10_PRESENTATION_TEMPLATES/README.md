# 10 Presentation templates
- `DN_Presentation-Template_16x9.pptx` is the master plus a 21-slide sample deck. `DN_Presentation-Master_16x9.potx` is the same file as a PowerPoint template. `DN_Presentation-Template_16x9.pdf` is the rendered check.
- The theme colours (Forest, Gold, Canopy, Confluence, Laterite, Sage) and theme fonts (Playfair Display headings, Inter body) apply automatically to new shapes, charts and tables.
- The 21 layouts are: Cover · Cover with photograph · Agenda · Section divider · Executive summary · Title and content · Two columns · Full-bleed photograph · Destination feature · Image grid · Title only (timeline, process, roadmap diagrams) · Statistics/KPIs · Chart · Investment opportunity · Partnership overview · Table/budget · Case study · Quote · Closing · Event holding slide · Blank.
- Picture placeholders crop to fill: use *Insert picture* inside the placeholder. The chart is a native PowerPoint chart (right-click → Edit Data). Slide numbers are built into the layouts.
- Google Slides: File → Import slides. The layouts carry over; add the fonts through *More fonts*.
