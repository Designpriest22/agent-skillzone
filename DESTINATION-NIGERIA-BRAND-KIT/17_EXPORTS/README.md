# 17 Exports
Production exports sit next to their sources in each numbered folder; for example `02_LOGO_MASTER_FILES/PNG` and `05_BACKGROUNDS_AND_TEXTURES/*/`.
`ESSENTIALS/` is a ready-to-share starter pack for partners and staff: primary logos (SVG, PNG), the roundel, the campaign line, colour swatches and the quick-reference sheet.
Save new derivatives here (`17_EXPORTS/YYYY-MM_project-name/`), never over the masters.
