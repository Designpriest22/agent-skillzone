# 12 Website assets
- `tokens/` holds `dn-tokens.css` (CSS custom properties) and `dn-tokens.json` (W3C design-token format): colour, UI states, fonts, type scale, spacing, radii.
- `components/` contains `dn-components.css` and the live demo `DN_components.html`. The demo covers buttons, links, search, destination, editorial and investment cards, form controls with error states, alerts, newsletter, map, 404 and empty states, the branded loader (`DN_loader.html`, which honours reduced motion) and the footer.
- `favicon/` contains favicon.ico (16/32/48), favicon.svg, PNG icons at 16–512 px, a maskable icon, site.webmanifest, a Safari pinned tab and `HEAD_SNIPPET.html`.
- `og/` contains the Open Graph cover (1200 × 630) and a square share image.
- `hero/` contains hero backgrounds (2560 × 1200 desktop, 900 × 1400 mobile) with a text-safe left zone.
- `section-backgrounds/` contains WebP versions of the background library.
- `map/` contains the MapLibre/Mapbox GL style (`DN_map-style_maplibre.json`; add your own licensed tile source), SVG maps, pin and route kit.
- Icons: `04_VECTOR_GRAPHICS_AND_ICONS/icons/DN_icons_sprite.svg`. Loading animation (Lottie): `07_MOTION_IDENTITY/LOTTIE`.
