# 12 Website assets (v2)
- `homepage/`: the homepage design, desktop (1440 px) and mobile (390 px), as live HTML plus full-page PNG renders.
- `tokens/`: `dn-tokens.css` and `dn-tokens.json` (colour, UI states, fonts, type scale, spacing, radii: square by default).
- `components/`: `dn-components.css` and the live demo `DN_components.html` (buttons, links, notices, figure with caption, form fields with error states, table, column groups).
- `images/`: web-sized JPG and WebP versions of the photo library.
- `hero/`: Agbokim Waterfalls crops, 1920 × 960 and 900 × 1400.
- `og/`: Open Graph image, 1200 × 630.
- `favicon/` (roundel) and `map/` (MapLibre style; bring your own licensed tiles).

**Accessibility:**
- Text pairs pass WCAG AA.
- The focus ring is 3 px Sun Gold.
- Motion respects `prefers-reduced-motion`.
- Every image has descriptive alt text naming the place.
