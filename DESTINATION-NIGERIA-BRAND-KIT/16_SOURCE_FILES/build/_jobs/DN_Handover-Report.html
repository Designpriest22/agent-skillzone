Rebuilding

Install the fonts and dependencies (16_SOURCE_FILES/README.md), then run 16_SOURCE_FILES/build/build_all.sh. To add a place: 1. Put a verified, licensed, high-resolution photograph in SUPPLIED_BY_CLIENT. 2. Add it to photo.py and brand.PHOTOS. 3. Optionally add a plate in plates.py. 4. Rebuild.
