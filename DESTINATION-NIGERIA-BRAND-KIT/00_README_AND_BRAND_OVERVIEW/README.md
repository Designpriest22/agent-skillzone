# Destination Nigeria: brand identity kit v2.0

*Experience. Invest. Explore.*

The brand identity system for Destination Nigeria, the national tourism development, investment and destination-marketing platform. v2 is a creative reset built on one idea: **the land, drawn and photographed.** The supplied logo is preserved exactly. Real photographs of real places, verified and captioned, lead the imagery, and engraved plates traced from those photographs give the brand its illustration language. Everything is generated from one source of truth (`16_SOURCE_FILES/build/brand.py`) and rebuilds with `16_SOURCE_FILES/build/build_all.sh`.
