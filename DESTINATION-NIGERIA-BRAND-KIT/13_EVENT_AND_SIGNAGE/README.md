# 13 Event and signage
All artwork is built at physical size with live text. Print items have a vector `_print.pdf` at true size, and `_previews/` holds PNG previews.

| Item | Spec |
|---|---|
| Programme | A4 + 3 mm bleed: cover and running order |
| Speaker profile | 1080 × 1350 (social or screen) |
| Stage screen | 3840 × 2160 LED/projection (16:9) |
| Media wall / step-and-repeat | 3000 × 2400 mm (add 50 mm bleed at production) |
| Digital invitation | 1080 × 1350 |
| Name badge | A6 + 3 mm bleed, with a colour band by role |
| Directional signs | A2: left, right, up |
| Sponsor acknowledgement | 1920 × 1080 with “approved partner logo” slots |
| Roll-up banner | 850 × 2000 mm (bottom 150 mm hidden) |
| Exhibition panel | 2000 × 1000 mm |
| Holding slide | PPTX layout 20, plus loop D |

These are templates. They do **not** imply that any event, including National Tourism Week, has been scheduled. Publish details only after official confirmation.
