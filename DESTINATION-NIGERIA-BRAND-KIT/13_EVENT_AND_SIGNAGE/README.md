# 13 Events and signage (v2)
Built at physical size in CSS millimetres. Print PDFs are vector at true size: the engraved plates and logo stay sharp at any scale. PNG previews are in `_previews/`.

| Item | Size | Files |
|---|---|---|
| Programme cover and running order | A5 + 3 mm bleed | `programme/` |
| Invitation | 5 × 7 in + 3 mm bleed | `invitation/` |
| Name badge | A6 | `badges/` |
| Wayfinding sign | A2 | `signage/` |
| Roll-up banner | 850 × 2000 mm visible + 100 mm base | `backdrop/` |
| Media wall (step and repeat) | 3000 × 2400 mm | `backdrop/` |
| Stage holding screen | 1920 × 1080 | `holding-slide/` |
| Speaker announcement | 1080 × 1350 | `speaker/` |
| Partner screen | 1920 × 1080 | `sponsors/` |

**Placeholders.** Event names, dates, venues, speakers and partners are bracketed placeholders. Nothing here implies that any event has been scheduled. Edit the HTML in each `source/` folder, or the generator `16_SOURCE_FILES/build/events2.py`.
