# 09 Document templates

These are Word templates with real styles (Title, Heading 1–3, Lead, Overline, Quote, Caption, Table Head/Text). Every placeholder is a **content control** in [brackets]: click it and type. Each DOCX has a PDF export alongside it, and the core set also has a `.dotx`.

| Folder | Files |
|---|---|
| LETTERHEAD | Standard and ceremonial letterheads; formal-correspondence layout (ref, date, recipient, subject, signature, enclosures, cc); continuation-page header |
| MEMO | Memo with reference, date, to/from/cc/subject, action-required box, approvals |
| REPORTS | Multipage report: cover, contents (TOC field), executive summary, chapter divider, body styles, data table, chart, captioned image, pull quote, recommendations, references, appendices, running footer with page numbers |
| PROPOSALS | Proposal / concept note: objectives, background, strategic alignment, implementation plan, outcomes, timeline, roles, budget (₦), risks, next steps |
| MEETING_MINUTES | Minutes: participants, agenda, discussion, decisions, actions, next meeting, approval |
| INVOICES | Invoice and quotation (DOCX) plus **calculating XLSX** (line totals, subtotal, VAT rate cell, total) |
| PRESS_AND_MEDIA | Press release, media advisory, official announcement, interview brief, fact sheet, media backgrounder; each has a source-verification line |
| WORKSHOP_MATERIALS | Agenda, attendance sheet, participant certificate, feedback form, workshop report, action-plan tracker (DOCX + XLSX with status drop-down) |
| INVESTMENT_PROFILE | Investment opportunity profile with data-status and due-diligence sections; unconfirmed values stay TBC |
| BUSINESS_CARDS | 85 × 55 mm, standard and premium, front and back. SVG sources (live text, mm units), bleed PDFs, crop-mark PDFs, 300 dpi PNGs. For a batch, add people to `staff.json` and run `cards.py` |
| EMAIL_SIGNATURE | Table-based HTML signature, preview, logo PNG, install guide |

**Fonts:** install the fonts from `03_COLOR_AND_TYPOGRAPHY/fonts` (Word) or add them in Google Docs. Without them, Word substitutes its defaults; use Georgia and Calibri as fallbacks.
**Nothing invented:** no address, phone number, bank details, registration number, seal or affiliation appears anywhere. These must come from the client.
