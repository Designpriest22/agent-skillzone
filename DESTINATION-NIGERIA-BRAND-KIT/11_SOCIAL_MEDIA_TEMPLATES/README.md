# 11 Social media templates (v2)
Seven compositions, each with a job, in 4:5 (1080 × 1350), 1:1 (1080 × 1080), 9:16 (1080 × 1920) and 16:9 (1200 × 675):

| Composition | Job |
|---|---|
| `place` | Lead with a real place (low horizon); verb label, place name, state |
| `plate` | An engraved plate, mounted and captioned; a short line |
| `statement` | A brand statement on Forest, with one sun |
| `invest` | An investment message under a photo band (high horizon), with the contact email |
| `figure` | One sourced figure, large |
| `explore-grid` | Four real places, captioned |
| `contact` | All supplied contacts, over Zuma Rock tone-on-tone |

**Editing:**
- Edit the copy in `content.json`, run `python3 16_SOURCE_FILES/build/social2.py`, then `node 16_SOURCE_FILES/build/render.mjs 16_SOURCE_FILES/build/_jobs/_jobs_social2.json`.
- Each `*/source/*.html` is a live artboard: edit the text in place, or import it into Figma with an HTML importer.

**Rules:**
- Use only verified, licensed photographs of the place named, with the caption.
- Every figure needs a source line.
- Never publish event dates or partners until they are confirmed.
