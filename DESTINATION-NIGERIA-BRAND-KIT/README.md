# Destination Nigeria: Brand Identity Kit v1.0

**EXPERIENCE. INVEST. EXPLORE.**

A complete brand identity system for Destination Nigeria, the national tourism development, investment and destination-marketing platform. It is built around the supplied logo, which is preserved exactly. Every asset is generated from one source of truth (`16_SOURCE_FILES/build/brand.py`) and can be rebuilt with `16_SOURCE_FILES/build/build_all.sh`.

**Start here:** `14_BRAND_GUIDELINES/DN_Brand-Guidelines_v1.0.pdf` (36 pp) · `14_BRAND_GUIDELINES/DN_Brand-Quick-Reference_v1.0.pdf` · `18_QA_AND_HANDOVER/DN_Handover-Report.md`
