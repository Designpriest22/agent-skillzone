# 06 Photography and media

- `LIBRARY/` holds the **graded masters** (`DN_photo_[place].jpg`): nine verified photographs of real Nigerian places, each with one restrained brand grade. Nothing is added or removed. The grade is defined in `16_SOURCE_FILES/build/photo.py`.
- `SUPPLIED_BY_CLIENT/` holds the client's files, untouched. `_rejected/` keeps the four images that were not used, and why: Crystal Bay is in Nusa Penida, Indonesia; `caption.jpg` is almost certainly Chamarel Falls, Mauritius; `images (6)` is a digital composite; and one file is a byte-identical duplicate.
- `SOURCE_RECORDS/image-register.csv` records, for every image: place and state, identification confidence, pixel size, maximum print width at 300 ppi, rights status, releases and notes.
- `LICENSES_AND_ATTRIBUTION/LICENSES.md` records the licences for everything in the kit.
