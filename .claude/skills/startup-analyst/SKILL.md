# Startup analyst

1. Context: stage, model, question.
2. Data: current, credible, cited sources with dates (government, industry reports, public companies).
3. Market: bottom-up AND top-down TAM/SAM/SOM; triangulate; show the formula and inputs.
4. Unit economics: CAC, LTV, payback, ARPU/ARPPU, conversion to payer, retention (D1/D7/D30 for consumer apps).
5. Projections: conservative / base / optimistic; document every assumption; break-even.
6. Competition: positioning map (2×2), substitutes, sustainable advantage.
7. Present: tables + charts, assumptions listed, risks and limitations stated, next steps.

Never: unsupported claims, optimistic-only assumptions, uncited numbers. A stated data gap beats an invented number.
Consumer/game metrics to prioritise: DAU/MAU, D1/D7/D30 retention, session length, payer conversion, ARPDAU.
