# Billboards

`public/game/billboards/*.webp` are 800×400 panels drawn on roadside billboards in every stage (see `BILLBOARDS` in
`src/game/client/render.ts`). Both were composed from TCM-supplied event posters:

- `odumodu.webp`: Odumodublvck "Rise of the Machine", Dec 20, Abuja (Kalacious Entertainment)
- `wizkid.webp`: Wizkid Live Out Loud Music Festival, 13 Dec, Eagle Square, Abuja

Sponsor logos and ticket links were left out: brand marks inside the game need each brand's own clearance.
To change a board, replace the file with another 800×400 image and rebuild.
